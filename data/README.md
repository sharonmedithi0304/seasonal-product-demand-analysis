# Dataset instructions

The notebook downloads the original **Online Retail II** workbook from the UCI Machine Learning Repository into `data/raw/online_retail_II.xlsx` on first run. The workbook is about 43.5 MB, so it is intentionally not tracked in this repository.

- Dataset page: https://archive.ics.uci.edu/dataset/502/online+retail+ii
- Direct workbook URL used by the notebook: https://archive.ics.uci.edu/ml/machine-learning-databases/00502/online_retail_II.xlsx
- Citation: Chen, D. (2012). *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D
- UCI lists the dataset under the Creative Commons Attribution 4.0 (CC BY 4.0) license. Preserve attribution when reusing the dataset.

Expected workbook sheets: `Year 2009-2010` and `Year 2010-2011`.
